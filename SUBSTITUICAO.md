# Substituição completa do projeto antigo

Este pacote inclui o rebuild Lexus e também sobrescreve os nomes de arquivos da loja antiga com redirects/arquivos neutros. Isso evita que páginas antigas continuem aparecendo caso o upload seja feito por cima do mesmo repositório no GitHub.

As imagens antigas são substituídas por arquivos transparentes mínimos. O histórico do GitHub continuará existindo, mas a versão publicada deixa de usar o conteúdo antigo.
