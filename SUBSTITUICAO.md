# Substituição da versão anterior

1. Extraia o ZIP.
2. Entre na pasta `lexus-produtos-pix-v5-launch`.
3. No repositório GitHub conectado à Vercel, use **Add file → Upload files**.
4. Arraste o conteúdo da pasta, preservando `api/`, `assets/`, `supabase/` e os arquivos da raiz.
5. Faça o commit e aguarde o deploy automático da Vercel.

Não apague as Environment Variables já configuradas.
